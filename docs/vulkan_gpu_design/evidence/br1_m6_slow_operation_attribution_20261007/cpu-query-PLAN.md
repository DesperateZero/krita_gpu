# D3 原始工作端点的低扰动CPU查询

D2固定16过程完成。产品操作起止同编号的分组出现明显慢/快两组，固定reference也慢；但预注册全量Pearson≥0.6仅4/16，ARM全未达，不宣称完成全部同步/因果解释。不能把同编号保证当作全区间驻留，不能把所有0–5直接叫能效核。

另冻D3有限32过程：2架×K1/K16×hit/native-pin，每桶4；512ms有效操作、至少512次、8warmup，轮转奇轮逆序。直接从上轮baseline-seed.cpp派生，只在原begin/end壁钟外查询CPU编号，原timed block保持字节相同；没有逐操作CPU/rusage或reference busy loop。固定SDK依据与32过程输入/语义/退出/库验证。

检查两种表示条件能否仍观察同编号分组的差异，比较实际0–5/6–9组（由D2观察形成，探索性，不作门禁）。逐过程保留完整向量；报告各组count、median、wall占比及端点迁移，记录≥1ms事件。32过程后停止，不以core筛样、不CPU归一化、不据分组替换全量吞吐裁决。低扰动仍非零扰动，无严格亲和/核类型/频率/外部负载轨迹时不授予因果百分比。
