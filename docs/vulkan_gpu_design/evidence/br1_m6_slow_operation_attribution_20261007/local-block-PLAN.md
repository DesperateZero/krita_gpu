# I1/V1 就地顺序块改动与固定对照

D3完成32过程/654950操作；30过程两组同编号样本均存在，0–5/6–9中位数比3.11–5.33。其余2过程无0–5组，不能填0或当相同。查询不是区间驻留证明；本轮没有核类型/频率/外部负载的精确因果比例，也没有产品可删时间预算。

领取一个有界实验编排责任，完整矩阵如下：

| 位置/consumer | 原责任与寿命 | 新表达/删除与保留 | 预测/验证 |
|---|---|---|---|
| runner组循环→pair循环 | 先全组AB，下一轮全组反向BA；同一桶的两个pair相隔其他桶 | 新local编排每桶就地ABBA/BAAB；原global编排同期保留作对照；不新增产品owner/状态 | 相邻两pair覆盖更短时间，可抵消局部线性漂移；异构核随机占用和固定process差异仍不能保证消失 |
| 原seed probe/sample | 每操作全新Store，同一exact初态，独立setup/验证/close/销毁/drain | 直接复用上轮未插桩probe-seed和两个已冻结镜像；所有timed work和统计估计量保持 | 无CPU/ref/编号计量；逐次向量全部保留，禁止删尾/归一化 |
| 四个D4残留组合 | ARM K1 native A/A、ARM K16 hit cross、Rosetta K1 native A/A及cross | 只用于验证新编排；不将旧12个成功组合与新4个拼成16/16或20桶资格 | 两策略同轮各12pair/6块，双侧95%描述性区间，paired log吞吐SD分别报告；非正式family |
| 失败/身份/退出 | 单进程120s kill/reap，失败不替换 | 完整保留原规则；输入/库SHA前后核验，所有语义工作验证 | 任何不一致停止，保留失败，不扩样到通过 |

固定192过程：6顺序块×2策略×4组合×2pair×2process。每过程累计512ms有效操作、min128、8warmup；每块旋转4组次序，global第二pair反转组次序；local同组两pair相邻。每块交替两策略先后，pair的AB/BA先后也按块交替。每组local与global均拥有同样process数量和有效窗口。random hash、原QoS不变。

估计量为两pair log吞吐比均值→6块中位数；bootstrap20000，seed261015，双侧95%描述性界。阈值仍±2%，只判断本诊断是否满足；SD变化是观察值，不能将原库/镜像点估计差扣除。预测是精度可能改善，不事先承诺全部组合满足。完成即停止；即使全部满足也须另冻结完整20桶正式family及匹配hit/miss，旧64ms正式2/20不追认。不满足则记录环境/编排分辨率仍不足，不继续同义扩窗、改seed、加样或猜改产品微路径。
