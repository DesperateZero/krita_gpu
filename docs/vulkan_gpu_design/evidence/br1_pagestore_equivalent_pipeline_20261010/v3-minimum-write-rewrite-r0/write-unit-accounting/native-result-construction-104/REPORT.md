## 动作上界与数值上沿的区别

限定D改变页、W批、F真实新物理、H实际复用、R实际新保留边、X真实导出/异步、Q有界重试、T末次物理终结。当前实现的可审计动作账为：

- 暖绑定：每页一次原PageSlot查找；只在缺页时建立槽并重新合并定位。页内维护随D，不随整个历史总规模扫描。
- 复用：每实际候选一次真实claim，每成功目标一次物理完成；共同预算按实际批发行，Warm H1为56个含复用的写批，而不是896个独立通用费用事务。
- Fresh：每F实际工厂、绑定、footprint、物理索引及出生lease一次；真实收费与预付终结保留。H1四寿命暖F128/H896，没有把F降成0。
- final：至多2D个原Resource变化，排序归并后一次目标动态验证/安装；真实all-D语义保留。至多D个adapter更新；区间查询当前仍有准备、重验、消费三处，不宣称已达绝对最小。
- 历史：本格暖R64，当前Selection切换D1024；按实际S和页内V索引，不为其余960个中间结果生成独立保留关系。
- failure：Q次Ready重验不重写内容；取消后的重新准备属于新的D/H/F工作，需另计。终结按实际T而不是按写次数付费；真实pin延迟须保留债务与再尝试次数。

这些动作边界与完整新价共同形成可执行预算；预测公式已跨规模验证。**尚不能证明任意并发/IO/内存压力下的严格指令最坏上界，也不能称9441条/页为功能下界。** 后续生产迁移应先以同一工作量不超过约9914条/页的规划线作回归判别，变化前重估新增公共接口/GPU服务价格；不准原封不动接回旧事务再称“迁移完成”。
