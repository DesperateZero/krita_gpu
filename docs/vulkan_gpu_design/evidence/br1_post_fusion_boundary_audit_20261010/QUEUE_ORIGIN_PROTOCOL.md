# 后续有限判别：16次重叠准备是否来自同一批输入区域

前一PROTOCOL的68进程已全部完成且不扩样。其4次页追踪均为56首次页、24次同页不相交区域、16次相交区域；矩形访问面积207840、并集164832。矩形重叠不是源像素未变的证明。

本补充只追踪这个新出现的16次重叠解释：同一次addJob的矩形列表是否已经重叠；local walkers尚未入队时tryMergeJob能否看到本批其它walker；最终merge身份与请求来源；overlay capture精确版本集合是否变化。保持原产品/夹具，在既有观察库副本上仅替换queue/merger/Store观察TU。

固定4进程current/upstream/upstream/current，全部lineage模式，无新增性能对照、不报价净收益。保留原68进程和分析结果；数量/输入身份用于选项，不把重观察时间纳入责任排名。相同退出、像素、生命周期、溢出与父子账校验，失败立即停。

输出判据：能把重叠归到同一addJob的输入矩形/拆分合并选择，或给出相反的来源证据。若仍缺来源则标未知，不再增加本包观测层级。源overlay版本集合摘要仅验证该scope捕获事实的一致性，不自动证明跨最后commit的所有像素相同。实施需另证合法替代和独立净收益；本判别不允许按40/96换算预测提速。
