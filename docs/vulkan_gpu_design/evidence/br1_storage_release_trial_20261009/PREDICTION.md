# 原物理释放候选裁决（单价后、产品前）

产品仍d182a34bd0，未改。计数A/B Stroke普通free5930/6066、低对齐映射各1；不同实际retry/回收调度使总量不完全相同，不把这136次差算为原型新增或删除。按每实际事件：普通malloc_size少1、低对齐映射少2，高对齐前缀少1，实质free/收费不变。

独立微单价过程256行全部capacity返回校验通过。普通64/512/4096/16384B的8块中位节省分别5.6257/4.5264/5.1973/4.7913ns/free；全块范围3.6221–6.0630ns。65536B和mmap受释放/VM变化影响有反向块，不能用其最高值外推普通小块。用实际5930–6066次乘小块价格，仅给**约0.02–0.04ms Stroke CPU的条件量级**；不是统计区间，也没有逐size分布足以形成精确加权预算。真实上下文/并发可能改变单价。

决定：**不作为本轮主优化，不实施产品补丁，不运行原定阶段2的64过程**。单函数清理可留作低优先级；不能为获得一次“成功优化”将主要目标缩成几ns微基准。这取得技能筛选的一次反例：大次数只有配上实际单价才有决策意义；仍没有证明技能正向净收益预测有效。

新事实是约6000次普通物理free跨前后台存在。下一判别改问“哪些具体对象造成这些完整分配/预算/释放协议”，不是继续测malloc_size。一次固定1/32栈采样取得调用者方向；只作机制定位，不给CPU占比，不重采时间数据。新问题/上限见SUPPLEMENT.md。
