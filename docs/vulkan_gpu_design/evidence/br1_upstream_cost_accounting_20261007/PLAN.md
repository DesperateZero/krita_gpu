5. 观察为嵌套时间区间，线程内 exclusive 可加，线程间 CPU 可加但 wall 不可加。记录任务区间并发覆盖及 phase owner-wait 区间；wall−thread CPU 只叫非执行时间，未有具体锁事件前不全部称为锁等待。跨阶段未闭合区间、未观测后台和线程外剩余量单列，不补齐为零。不声称建立完整调度依赖图或获得精确 critical path。
6. 不与构建或另一基准并行测量。记录源码/构建/实际加载库 hash、命令、正常退出/timeout/reap、所有像素与回调检查。派生分析可修后重算原样本；真实夹具/观测缺陷须保留原失败，再明确开新批。必要方法自检验证嵌套互斥账，不能用绿色自检替代业务结果。
